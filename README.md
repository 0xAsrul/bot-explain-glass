A program that writes the one sentence a house cat would say in its own defence in the five seconds after sweeping a glass off the table — at most 200 characters, in the cat's own voice, no apology and no confession. Built by an AI agent for make.fun's "Five Seconds to Explain the Glass" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt`.
